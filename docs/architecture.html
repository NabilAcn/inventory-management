Factory Inventory Management System

A full-stack demo: Vue 3 single-page app, a Python FastAPI service, and in-memory data loaded from JSON files. There is no database.

The browser calls the API directly over HTTP (axios to http://localhost:8001/api). CORS is enabled on the backend so the two origins can talk. Data is read-only apart from in-memory state, and resets on restart.

Data Flow

  1. Filter selection. The user changes Time Period, Warehouse, Category, or Order Status in the filter bar. State lives in the shared useFilters composable (a module-level singleton, so every view sees the same values).
  2. API call. A view calls a method in client/src/api.js. It converts the filters to query parameters, skipping any set to all.
  3. Routing and filtering. FastAPI matches the route and applies the filters in memory with apply_filters and filter_by_month.
  4. Validation. Pydantic models (InventoryItem, Order, BacklogItem, ...) validate and serialize the response as JSON.
  5. Rendering. The view stores raw results in refs (allOrders, inventoryItems). Computed properties derive totals and chart data, and Vue re-renders.

How the Swagger UI on Port 8001 Works

Opening http://localhost:8001/docs shows an interactive API reference. No one wrote or configured it. It is a built-in feature of FastAPI, produced by the pieces below.

  • OpenAPI schema. FastAPI inspects each @app.get(...) route, its parameters and type hints (such as Optional[str]), and its response_model. From these it builds an OpenAPI 3 document, served as JSON at /openapi.json.
  • Pydantic. The models (InventoryItem, Order, ...) provide the JSON Schema for each request and response, including field names and types. The same models validate the data at runtime, so the docs cannot drift from the code.
  • Swagger UI. /docs returns a small HTML page that loads the open-source Swagger UI JavaScript and CSS (from a CDN by default) and points it at /openapi.json. The browser renders the endpoints and lets you click Try it out to send real requests to the running server.
  • ReDoc. /redoc renders the same schema as a read-only reference page.
  • Serving. Uvicorn, an ASGI server, listens on port 8001 (uvicorn.run(app, host="0.0.0.0", port=8001) in main.py). FastAPI is built on Starlette, which handles routing and the CORS middleware.

Because the Swagger page pulls its assets from a CDN, it needs internet access in the browser. The API itself does not.
